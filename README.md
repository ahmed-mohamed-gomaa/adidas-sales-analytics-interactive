## 📊 Project Overview

This project analyzes Adidas Middle East sales data to uncover regional trends, product performance, and key revenue drivers. By leveraging dynamic formulas, structured pivot tables, and an interactive dashboard, users can seamlessly drill down into specific sales metrics to evaluate business growth.

### Key Objectives
* **Sales Performance Tracking:** Analyze total sales, operating profit, and units sold across different US states and regions.
* **Product Analysis:** Identify top-performing footwear and apparel segments.
* **Retailer Benchmarking:** Compare sales across major retail channels and methods (In-store, Online, Outlet).
* **Dynamic Visualizations:** Build a user-friendly dashboard for quick Executive-level decision-making.

## 📈 Dashboard Features & Insights

The interactive dashboard included in the workbook provides:
* **Slicers & Filters:** Filter the entire dataset by **Region**, **State**, **Retailer**, and **Sales Method** with a single click.
* **KPI Cards:** High-level summaries of total revenue, profit margins, and sales volume.
* **Trend Charts:** Monthly and quarterly sales timelines to track seasonal performance.

## 🚀 How to Use the Project

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/ahmed-mohamed-gomaa/adidas-us-sales-dashboard.git](https://github.com/ahmed-mohamed-gomaa/adidas-us-sales-dashboard.git)
    ```
2.  **Open the File:** Launch the `.xlsx` file using Microsoft Excel (recommended) or any compatible spreadsheet software.
3.  **Interact:** Navigate to the `Dashboard` sheet and use the visual slicers to explore the data dynamically. *Make sure to enable macros/external content if prompted for full functionality.*
